# Kayamkulam Kochunni (subagent report, condensed; agent opened URLs, some via summariser; Malayalam Wikisource unreachable)
Match: real 19th-c. Travancore highwayman (Muslim, from Kayamkulam); Aithihyamala (Sankunni) chapter (Part 4, ch.34 per Sayahna; Book II story 13 per Wikipedia - numbering differs) includes gave-to-poor / targeted-rich-who-refused-charity element. "Stole from the rich to feed the poor" = folklore only (Kerala Folklore: existence confirmed by records, generosity not). Oversimplification: sources also mention killings, drugging, temple theft, drinking. "Feed" is more specific than sources ("give money/help"). Subtitle "robber with a kind heart" is a modern shelf label. No ballad tradition found (do not claim one). Pakki friendship = later folklore (2018 film invents it per Silverscreen).

Death accounts differ (1859/1895 TB/hanged).
