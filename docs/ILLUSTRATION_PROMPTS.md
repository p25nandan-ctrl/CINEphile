# Illustration prompts and asset manifest

**Status: no illustrations have been generated for these 26 stories.** The tools available in this project cannot produce raster artwork, so every story still shows a "Picture to come" panel. Only the two Kerala stories (A Friend in Need, The Clever Jackal and the Foolish Leopard) have pictures, and those are vector drawings made in code, not watercolour paintings.

## House style (apply to every prompt)

Traditional Indian folktale storybook illustration; soft hand-painted watercolour; warm earthy colours, natural greens, subtle highlights; expressive characters; detailed regional backgrounds; gentle, child-friendly mood. No text, titles, captions, watermarks or borders in the image. Keep each character looking the same across a story (see character notes). Do not borrow Kerala-specific motifs for other states.

## Format notes

- The book layout currently shows each picture in a frame of about 346:283 (roughly 1.22:1). The brief asks for 16:9. Either generate at 16:9 and let the frame crop, or change the frame ratio in pages.css; this needs a decision.
- Same image is shown on the English and Hindi pages. Reuse across the three reading levels (scenes are shared).
- Wiring: save each file as `assets/stories/<story-id>/scene-<n>.webp` and set `sceneImages` on the story (the book engine already supports it).
